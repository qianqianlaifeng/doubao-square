💡 电脑端使用建议

  1. 优先用「新标签页打开」按钮：豆包是单页应用，部分功能（登录验证码、扫码、上传）在内嵌框里可能受限，新标签体验最稳。
  2. 登录方式：支持手机号 + 验证码，或抖音 App 扫码。首次使用建议先登录再创作。
  3. 内嵌空白怎么办：如果下方预览区一直转圈或空白，说明豆包临时限制了内嵌显示——直接点上面的「🚀 打开（新标签页）」即可。
  4. 找不到入口：电脑浏览器建议用 Chrome / Edge，并开启硬件加速（设置 → 系统 → 使用硬件加速）。
